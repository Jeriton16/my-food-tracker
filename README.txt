MY FOOD TRACKER — ANDROID HOME-SCREEN APP

WHAT'S INCLUDED
- Daily food diary with breakfast, lunch, snacks and dinner
- Calorie, protein, carbohydrate, fat and fibre totals
- Water and weight tracking
- Editable daily goals
- CSV export and JSON backup/restore
- Offline support after first visit

IMPORTANT
Food nutrition values are estimates per 100 grams. Recipes (especially curries) vary.
All entries are saved in this browser on this device. Clearing browser data can erase them.
Use Backup data (JSON) regularly. A backup does not automatically sync to another phone.

TO PUT IT ON YOUR ANDROID HOME SCREEN
This project must be hosted on an HTTPS website for installation as a PWA.
One free method is GitHub Pages:
1. On a computer, create/sign in to a GitHub account.
2. Create a new public repository, e.g. my-food-tracker.
3. Extract the ZIP first. Upload ALL files from the extracted folder to the repository's root (not the ZIP itself). Include the .nojekyll file and both PNG icons.
4. In repository Settings > Pages, choose Deploy from a branch, select main and /(root), then Save.
5. Wait for GitHub Pages to publish. It will show a website address.
6. Open that HTTPS address in Chrome on your Android phone.
7. Tap Chrome's three-dot menu > Install app (or Add to Home screen) > Install.
8. Open the app from your home screen.

The app does not require a Play Store listing. Keep the repository public for free GitHub Pages hosting.
This starter app has no account/login or cloud sync. It stores data locally in your phone's browser.

TO CHANGE THE FOOD LIST
Open app.js and edit the foods array near the top. Values are kcal, protein, carbs, fat and fibre per 100g.
